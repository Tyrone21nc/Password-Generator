# Password-Generator
This password generator mainly allows a user to generate a password using a keyword and save it onto a MongoDB database.
The keyword can be the user's name, nickname, words with meaning to the user.
## Steps:
#### 1. Clone the repository
#### 2. Open an Integrated Development Environment (IDE) and copy and paste the contents of the file in Python file, a file ending with ".py".
#### 3. Once you paste it, open up the terminal and then run the python file
#####   3.1 To run the file on terminal do: "python file_name.py"
#####   3.2 To quiz after running the file type: "ctrl + c"
